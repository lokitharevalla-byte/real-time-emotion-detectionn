# Real-Time Emotion Detection System

## Project Description

This project detects human emotions from facial images using Deep Learning.

The user uploads a facial image, and the system analyzes the face and predicts the corresponding emotion.

## Features

* Upload facial images
* Automatic face analysis
* Emotion detection
* Confidence score display

## Emotions Detected

* Angry
* Disgust
* Fear
* Happy
* Sad
* Surprise
* Neutral

## Technologies Used

* Python
* DeepFace
* TensorFlow
* OpenCV
* Google Colab

## How to Run

1. Open the `emotion_detection.ipynb` file in Google Colab.
2. Install the required libraries.
3. Run the notebook cells.
4. Upload a facial image.
5. The system displays the predicted emotion and confidence scores.

## Project Output

The system analyzes the uploaded facial image and displays the detected emotion.
